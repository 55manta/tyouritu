## 詳しい説明（4000文字以内）

```
調律ノートは、ピアノ調律師のための台帳アプリです。

■ 年に一度のリピートを、取りこぼさない

調律は1年に一度めぐってきます。ところが「そろそろかな」と思っているうちに、
調律師とお客様の双方が「相手からの連絡待ち」になり、気づけば数年が空いてしまう。
これは腕の問題ではなく、思い出す仕組みが無いだけです。

このアプリは、次の調律の時期が来たお客様を、開いた最初の画面に並べます。
「時期を過ぎています」「今月が時期」「来月が時期」「長期ご無沙汰」の4つに分けて、
今日どこへ声をかければよいかが、ひと目で分かります。

■ ご案内は、ボタンひとつで

ご案内の文章は自動で組み立てます。お客様のお名前、ピアノの部屋と機種、
次回の時期、料金の目安まで入った文面ができるので、そのまま LINE・SMS・メールで送れます。

送る前に本文は必ず全部お見せします。読まずに送ることはありません。

お客様には専用のページが届き、「お願いします」か「今回は見送ります」を押すだけ。
アプリを入れていただく必要はありません。お返事はあなたの画面に戻ってきます。

日付はお客様に選ばせません。日程はあなたが決めるので、予約が重なりません。

■ 現場で使える記録

1台2〜3時間の作業の直後に、キーボードをほとんど出さずに終われるようにしました。
作業内容・料金・基準ピッチ・湿度・メモは、よく使うものを選ぶだけ。
作業前と作業後の写真も残せます。

定期調律だけが次回の時期を動かします。修理や運搬を記録しても、調律の周期は狂いません。

■ 売上も、そのまま

記録した料金が、そのまま今月の売上・月別のグラフ・年間の売上帳になります。
入金待ちのお仕事も一覧で分かります。消費税は免税・課税を切り替えられます。

■ お客様の情報を、大切に

お客様のお名前・ご住所・お電話番号は、調律師とお客様の信頼そのものです。

・台帳はまずお使いの端末の中に保存します。圏外でも使えます
・サインインしておくと控えが残り、端末を無くしても新しい端末で元どおりに開けます
・お客様に届くページには、お名前とピアノと料金の目安しか載りません。
　ご住所・お電話番号・メモ・写真・売上は一切載りません
・お宅の中の写真は、お客様ごとに保存の同意をうかがい、
　辞退されたお客様では最初から撮れないようにしています
・写真はお使いの端末の中だけに保存します

■ ご利用料金

無料でお使いいただけます。アプリ内での課金は現在ありません。
お客様の登録は10軒までを無料の目安としており、それを超える場合のプランは
設定画面からお選びいただけます。
登録済みのお客様は、いつでもご覧いただけます。

■ こんな方に

・お一人で、または少人数で調律をされている方
・お客様の台帳が、手帳やExcelに散らばっている方
・「そろそろ連絡しなければ」と思いながら、後回しになりがちな方
```

## データセーフティ（実装に即した申告）

このアプリが**実際に**何を扱っているかを、コードに即して書き出したもの。
実装を変えたら、この表と Play の申告も直すこと。

### 収集して端末外へ送るもの

| Play の申告名 | 中身 | 収集/共有 | 必須か | 用途 |
|---|---|---|---|---|
| 個人情報 / 名前 | お客様の氏名 | 収集のみ | 任意 | アプリの機能 |
| 個人情報 / メールアドレス | お客様のメール＋本人のサインイン用メール | 収集のみ | 任意 | アプリの機能・アカウント管理 |
| 個人情報 / ユーザー ID | Firebase の uid | 収集のみ | 任意 | アプリの機能・アカウント管理 |
| 個人情報 / 住所 | お客様のご住所 | 収集のみ | 任意 | アプリの機能 |
| 個人情報 / 電話番号 | お客様のお電話番号 | 収集のみ | 任意 | アプリの機能 |
| アプリのアクティビティ / その他のユーザー作成コンテンツ | 作業メモ・料金・ピアノの情報 | 収集のみ | 任意 | アプリの機能 |

「一時的に処理する」はすべて「いいえ」。第三者との共有はひとつも無い。

この申告は `store/data-safety.csv` に機械可読な形で置いてある。
Play Console の「CSV からインポート」に読ませれば、5ステップぶんが一度に入る。
画面をひとつずつ押していく必要はない。

すべて **サインインした場合にだけ** 送られる。サインインしなければ端末から出ない。

### 端末の中だけで、外へ送らないもの

- **写真**（作業前・作業後）。Cloud Storage を使っていないため、端末の外へ出ない
- 表示テーマ・消費税の設定などの環境設定（サインイン時のみ控えとして送る）

### 収集していないもの

- 位置情報、連絡先（端末の電話帳）、通話履歴、SMSの中身、
  健康・フィットネス、金融情報、閲覧履歴、検索履歴、インストール済みアプリ一覧
- 広告ID。**広告は一切入れていない**
- アナリティクス。Google アナリティクスは無効にしてある
- クラッシュログ。Crashlytics を入れていない

### 送信時の扱い

- 通信は暗号化される（Firebase の HTTPS/TLS）
- 利用者はデータの削除を求められる（アプリ内でお客様を削除すると、控えも消える）
